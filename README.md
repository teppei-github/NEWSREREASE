# セミナーリリース下書きジェネレーター（GAS）

日々のニュースリリース作成の **手順2（内容の整理）** と **手順3（リリース文の下書き作成）** を自動化する Google Apps Script アプリ。

- 入力：セミナーLPのURL（取得できない場合は本文貼り付け）
- 手順2：Gemini API がLPを解析し、テーマ／開催概要／ターゲット層／「こんなことが学べます」を構造化
- 画面で内容を確認・修正
- 手順3：会社情報（設定シート）＋過去リリース（文体の手本）を踏まえて Gemini がリリース文を生成し、**Googleドキュメントに下書き保存**

手順4以降（PRTIMES下書き、WordPress、PDF化、社内メール、公開）は対象外。

---

## ファイル構成

| ファイル | 役割 |
|---|---|
| `appsscript.json` | マニフェスト（スコープ・Webアプリ設定） |
| `Config.gs` | 設定シート／過去リリースシートの読み込み・雛形作成 |
| `LpFetcher.gs` | LPのURL取得とHTML→テキスト抽出 |
| `GeminiClient.gs` | Gemini API 呼び出し |
| `Analyze.gs` | 手順2：LP本文 → 整理結果(JSON) |
| `Draft.gs` | 手順3：整理結果 → リリース文 → Googleドキュメント |
| `WebApp.gs` | Webアプリのエントリポイント |
| `Index.html` | 入力・確認・生成のUI |

## セットアップ

### 1. プロジェクトを作る

**方法A：スプレッドシートにバインド（推奨）**
1. 新しい Google スプレッドシートを作成（このシートに設定を書く）
2. 拡張機能 → Apps Script
3. この 8 ファイルを貼り付け（`appsscript.json` はプロジェクトの設定 → 「`appsscript.json` を表示」をON）

**方法B：clasp**
```bash
npm i -g @google/clasp
clasp login
clasp create --type webapp --title "seminar-release-generator"
clasp push
```
スタンドアロンの場合はスクリプトプロパティ `SETTINGS_SPREADSHEET_ID` に設定用スプレッドシートIDを入れる。

### 2. Gemini APIキーを取得

<https://aistudio.google.com/apikey> で発行（無料枠あり）。

### 3. 設定シートを初期化

Apps Script エディタで関数 `setupSettingsSheet` を実行 → 「設定」「過去リリース」シートが作られる。

**「設定」シート**（A列=キー / B列=値）に記入：

| キー | 内容 |
|---|---|
| `GEMINI_API_KEY` | 取得したAPIキー（必須） |
| `GEMINI_MODEL` | 省略可。既定 `gemini-2.0-flash`。品質重視なら `gemini-2.5-pro` |
| `DRIVE_FOLDER_ID` | 下書きDocの保存先フォルダID（空ならマイドライブ直下） |
| `会社名` `事業内容` `ミッション` | リリースの「なぜ当社が」に使用 |
| `会社概要文` | リリース末尾に載せる定型文 |
| `今後の事業展開` | 終盤の段落に使う中期方針 |
| `担当部署` `問い合わせ先` | 問い合わせ欄に使用 |

**「過去リリース」シート**：A列の各セルに、過去のリリース文を1本ずつ貼り付け（最大3本を文体の手本として使用）。

### 4. Webアプリとしてデプロイ

エディタ右上 **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**
- 実行するユーザー：自分
- アクセスできるユーザー：組織内（`appsscript.json` で `DOMAIN` 指定済み）

発行されたURLを開いて使う。

## 使い方

1. LPのURLを入力 →「LPを分析して整理する」
2. STEP 2 で抽出結果を確認・修正（`【要確認】` や「要確認項目」は必ず埋める）
3. 「リリース文の下書きを生成する」→ Googleドキュメントのリンクが出る
4. ドキュメントを開いて仕上げ、以降は従来どおり手順4へ

---

## 注意

- LP取得は `UrlFetchApp`。JavaScriptで描画されるLPや認証必須ページは本文が取れないことがある → 本文貼り付けで対応。
- Gemini出力は下書き。事実（日時・料金・URL・登壇者）は必ず人が確認する。プロンプトで不明箇所は `【要確認：〇〇】` と出すよう指示済み。
- APIキーは設定シートに置く運用。シートの共有範囲に注意。
